# Experiment 004 protocol

Status: frozen-ready-for-launch for design purposes only. E004 was not
executed during this freeze.

## Primary question

How do SWE-2 Medium and Max compare on newly constructed, withheld software
defects calibrated to approximately the difficulty of the historical E002
cases?

The five cases are E004-N01 through E004-N05. Each has one Medium run and one
Max run, for ten planned runs. The cases are newly constructed, independent of
the E003 implementations, and are not copies of historical BugsInPy bugs.

## Frozen cases

| Case | Ordinary project | Failure class | Visible symptom |
|---|---|---|---|
| E004-N01 | buildgraph | dependency graph invalidation | a cached top-level plan remains stale after a source artifact changes |
| E004-N02 | taskqueue | resource lifecycle and replacement | a later job cannot obtain a worker after an operational error |
| E004-N03 | preferences | transaction rollback and ownership | an exception during a nested edit changes saved state |
| E004-N04 | signalhub | event dispatch and reentrancy | subscriber mutation can skip another subscriber |
| E004-N05 | reportpipe | multi-stage batch processing | a final partial batch is absent from the written report |

The detailed difficulty comparison is in
`docs/experiment-004-difficulty-calibration.md`. Source, prompts, fixed trees,
reference patches, held-out tests, and solution-bearing metadata remain in a
private local staging area.

## Success and evaluation

The agent receives only a fresh sanitized buggy workspace and the task prompt.
Each case has public tests, evaluator-only behavioral tests, and regression
tests. TASK_SUCCESS requires the required public, held-out, and regression
suites to pass. An evaluator infrastructure failure is recorded separately
from an agent repair failure.

The Medium and Max prompts for each pair are byte-for-byte identical. The
evaluator is outside the agent container and becomes available only after the
agent session closes. No reference tree, held-out test, previous result, or
paired result is mounted into the agent workspace.

## Isolation and limits

E004 uses the proven E002 Docker architecture and the frozen E002 Devin image:
Linux/arm64, read-only root filesystem, dropped capabilities,
`no-new-privileges`, no Docker socket, no host or control-repository mount,
one read-only credential file, and the existing restricted service proxy. Case
dependencies are not installed from the agent session.

The frozen limit is 3,600 seconds per session, with 4 GiB memory, 4 CPUs, and
a 512-process limit. There is no artificial step or token cap, one run is
active at a time, and ordinary task failures are not retried. These limits are
not intended to truncate E002-comparable tasks.

## Run order

The ten-run order is generated by `Python random.Random` with seed `20260923`.
It contains five Medium and five Max runs, keeps conditions interleaved with no
run of more than two identical conditions, and separates each case pair.
The authoritative order is in `manifests/experiment-004-runs.json`.

## Provenance and embargo

The private provenance record stores creation and freeze timestamps, hashes of
buggy and fixed trees, prompts, visible and evaluator tests, reference patches,
workspace exports, evaluator and runner versions, isolation configuration,
model assignments, and run order. The public freeze manifest contains hashes
and non-solution protocol metadata only.

The provenance claim is limited to newly constructed and withheld benchmark
instances. It does not claim impossible absolute exclusion from model training
data. Solution-revealing case content remains private until all ten runs close.

## Freeze boundary

Before freeze, the private validator reproduced the intended failure in every
buggy case, passed all public/held-out/regression suites on every fixed case,
passed repeated determinism checks, passed all ten workspace leak audits, and
verified that reference patches reconstruct the fixed trees. Isolation was
validated by static/dry-run compatibility checks only. Devin and SWE-2 were not
invoked.
