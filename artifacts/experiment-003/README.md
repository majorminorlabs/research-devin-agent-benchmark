# Experiment 003 public artifacts

E003 is the five-case paired pilot on newly constructed software defects. After all ten runs closed, the public package was expanded to include the buggy and fixed case trees, visible tests, held-out behavior tests, nearby regression tests, reference patches, prompts, patches, evaluator outcomes, sanitized timelines, and run metadata. Hidden reasoning, credentials, raw environment dumps, and private session exports remain excluded.

Medium scored 5/5 and Max scored 5/5. See `../../reports/experiment-003-results.md`, `../../reports/devin-swe2-reasoning-effort-v2.md`, and `../../results/publication-summary-v2.json`.
