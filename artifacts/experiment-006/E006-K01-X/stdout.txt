## Root cause

Black's parser never consulted `--target-version` for the `async`/`await` keyword distinction. `blib2to3`'s tokenizer treated them as soft keywords unconditionally: `async`/`await` emitted `NAME` tokens except inside `async def` bodies (`async_def` flag) or when `async` was stashed and followed by `def`/`for`. So `def async():` parsed under `py37`, and `x async for x in y` inside a *sync* function parsed under `py36` — both should fail.

## Changes

**`blib2to3/pgen2/grammar.py`** — `Grammar` gains an `async_keywords` flag (default `False`); `copy()` propagates it. Old pickles stay safe since `load()` updates `__dict__` on an initialized instance.

**`blib2to3/pgen2/tokenize.py`** — `generate_tokens(readline, grammar=None)` reads `grammar.async_keywords`; when set, `async`/`await` always emit `ASYNC`/`AWAIT` tokens. Also restricted the stash-upgrade to `token=<redacted> 'def'` (matching CPython's lib2to3 — the fork's `'for'` entry wrongly accepted `async for` outside `async def`, which is invalid pre-3.7; inside `async def` the `async_def` flag already covers it).

**`blib2to3/pgen2/driver.py`** — `parse_stream_raw`/`parse_string` pass `grammar=self.grammar` to the tokenizer.

**`blib2to3/pygram.py`** — new `python_grammar_no_print_statement_no_exec_statement_async_keywords` grammar with `async_keywords = True`.

**`black.py`** — new `Feature.ASYNC_IDENTIFIERS` (PY27–PY36) and `Feature.ASYNC_KEYWORDS` (PY37+); `get_grammars()` returns the hard-keyword grammar for 3.7+ targets, the soft-keyword grammar for ≤3.6, and tries hard-then-soft (then py2 grammars) when no target is given — so default formatting is unchanged.

**`.pyi` stubs** — updated `grammar.pyi`, `tokenize.pyi`, `pygram.pyi` (also dropped the nonexistent `python_grammar_no_exec_statement` entry).

Verified matrix: identifiers parse under py27/py36/default and fail under py37; `x async for x in y` in a sync function parses under py37/default and fails under py36; `async with`/`async for`/`await`/async comprehensions inside `async def` parse everywhere.
