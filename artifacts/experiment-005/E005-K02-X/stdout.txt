## Root cause

`SimpleTaskState.prune()` performs the lifecycle transitions — including resetting `FAILED` tasks back to `PENDING` once `retry_delay` elapses — but `CentralPlannerScheduler.prune()` was only invoked from the RPC-facing API methods (`graph`, `task_list`, `worker_list`, etc.), never from `get_work`. For the local scheduler, retried external tasks (`retry_external_tasks`) therefore stayed `FAILED` forever, and the scheduler constructor also rejected the `prune_on_get_work` option the test suite passes.

## Change (`luigi/scheduler.py`, 2 hunks)

- Added `prune_on_get_work = parameter.BoolParameter(default=False)` to the `scheduler` config class (line 102)
- Call `self.prune()` at the top of `get_work` when the flag is enabled (lines 715-716)

This matches upstream luigi, and the `False` default leaves ordinary scheduling paths untouched.
