## The bug

`Bash.app_alias` generated:

```
TF_ALIAS=fuck alias fuck='PYTHONIOENCODING=utf-8 TF_CMD=$(TF_SHELL_ALIASES=$(alias) thefuck $(fc -ln -1)) && eval $TF_CMD'
```

`TF_ALIAS` was a prefix on the `alias` builtin itself, and `PYTHONIOENCODING`/`TF_CMD` were bare (unexported) shell assignments inside the alias body — none reached the `thefuck` subprocess in `$(...)`. `Zsh.app_alias` had the same problem: all env vars were unexported assignments preceding `TF_CMD=$(...)`, so `thefuck` saw no `TF_ALIAS`, `TF_SHELL_ALIASES`, or `PYTHONIOENCODING`.

## The fix

Moved the context variables inside the command substitution as prefixes on `thefuck`, so they're exported into its environment — [bash.py:8-13](file:///workspace/thefuck/shells/bash.py) and [zsh.py:9-14](file:///workspace/thefuck/shells/zsh.py):

```
alias fuck='TF_CMD=$(TF_ALIAS=fuck PYTHONIOENCODING=utf-8 TF_SHELL_ALIASES=$(alias) thefuck $(fc -ln -1)) && eval $TF_CMD && history -s $TF_CMD'
```

The `alter_history` settings (`history -s` for bash, `print -s` for zsh) are preserved unchanged.
