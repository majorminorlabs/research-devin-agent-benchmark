# Experiment 004 public artifacts

Experiment 004 is the five-case paired benchmark on newly constructed, E002-calibrated software defects. Each case ran once with SWE-2 Medium and once with SWE-2 Max in the frozen interleaved order.

The public derivatives include sanitized prompts, agent patches, reference patches, evaluator statuses, observable session timelines, and run metadata. Hidden reasoning, private evaluator source, credentials, fixed trees, and full workspaces are excluded.

Medium scored 5/5 and Max scored 4/5. See [the results report](../../reports/experiment-004-results.md) and [the machine-readable summary](../../results/experiment-004-summary.json). The frozen order is in [the E004 run manifest](../../manifests/experiment-004-runs.json).
