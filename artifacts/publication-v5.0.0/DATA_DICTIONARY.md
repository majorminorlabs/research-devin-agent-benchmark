# Data dictionary

All CSV tables are generated by `scripts/build_publication_v5.py` from the original E007/E008 JSON ledgers and evaluator outputs. `true` and `false` are binary pass/fail outcomes; blank values represent unavailable source metadata and are not imputed.

## `data/e007_runs_sanitized.csv`

One row per E007 agent session (90 rows). Includes case, difficulty, effort, historical evaluator outcome, individual suite statuses, steps, observed duration, and token counters. `timing_available=false` identifies the one High run with missing wrapper duration. Session IDs, names, commands, paths, prompt hashes, exports, and traces are excluded.

## `data/e007_clean_rechecked_case_outcomes.csv`

One row per fixed case (30 rows), with clean-rechecked outcome at each effort. Medium and Max values are joined from the E008 replication matrix; High and all affected very-hard outcomes derive from the machine-readable E008 evaluator-recheck outputs. Unaffected historical results remain as recorded.

## `data/case_level_replication.csv`

One row per case (30 rows) for the original-to-E007 Medium and Max comparison. Each effort has original outcome, historical E007 outcome, clean E007 outcome, and clean-recheck agreement flag. This is the basis for stable solves/failures and directional changes.

## `data/e008_targeted_runs_sanitized.csv`

One row per E008 session (33 rows) with approved slot, case, difficulty, effort, repetition, final outcome, suite statuses, session telemetry, initial adapter-error flag, intervention count, and unknown cost status. Session IDs, names, commands, paths, exports, and traces are excluded.

## `data/five_observation_sequences.csv`

One row per selected case/effort condition (11 rows). Columns list original, E007 clean recheck, and E008 repeats one through three; totals and consistency labels describe those five observations only.

## `data/publication_summary.json`

Machine-derived aggregate counts, tier counts, agreement composition, and selected-repeat totals. No cost value is inferred.
