## Summary

**Bug:** `bool()` / `len()` on a `tqdm` instance created with `disable=True` and a `total` (or no iterable) raised `AttributeError: 'tqdm' object has no attribute 'total'`.

**Diagnosis:** In `tqdm/__init__` (`_tqdm.py`), the `disable` early-return path initialized `iterable`, `disable`, `pos`, and `n` but never set `self.total` or `self.leave`. `__len__` reads `self.total` when `self.iterable is None` (line 869), so any disabled bar without an iterable reported incorrect state — `total=10` bars crashed instead of being truthy, and bare `tqdm()` raised `AttributeError` instead of the expected `TypeError`.

**Fix** (`/workspace/tqdm/_tqdm.py:757-758`): initialize `self.total = total` and `self.leave = leave` in the disable branch — matching upstream tqdm's fix for this bug.
